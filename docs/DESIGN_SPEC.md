# 屏幕夹子 · 视觉与交互规范

版本 1.0，2026-10-12。此规范对应已实现的原生组件；早期产品草案保留用于说明产品判断。

## 视觉系统

| 元素 | 规则 |
|---|---|
| 主色 | 墨绿色，RGB 0.23 / 0.40 / 0.39 |
| 卡片 | 系统内容背景色，深浅色随系统变化 |
| 金属夹 | 银灰渐变、细边与线环；唯一的卡片移动把手 |
| 纸签 | 黄色 12% 透明度底色；承载用途与标签，文字始终可辨认 |
| 圆角 | 收起项 8 pt，展开卡片 13 pt，内部块 4–9 pt |
| 字体 | 系统字体，标题 13 pt，正文 14 pt，操作与备注 10–12 pt |
| 阴影 | 卡片原生窗口阴影；设计展示额外使用浅阴影区分层级 |
| 尺寸 | 收起 112 × 44 pt，展开初始 320 × 420 pt，停靠间距 8 pt |

图片缩放保持原比例。实际内容区域不叠加纹理。标签的颜色仅作辅助，分类始终显示文字。应用图标由 AppKit 绘制，金属夹由 SwiftUI 绘制。

## 动作与状态

| 输入 | 结果 |
|---|---|
| 停留约 350 ms | 临时展开 |
| 离开约 450 ms | 非保持展开的靠边卡片收回 |
| 点击收起项 | 保持展开，直到外部点击或主动收回 |
| 拖金属夹 | 在屏幕内常驻，或靠近左右边缘 42 pt 收起 |
| 拖图片或内容把手 | 原生跨应用复制拖放 |
| 单击内容把手 | 复制该夹项 |
| 双击展开卡片标题 | 打开文件、文件夹或链接 |
| 点纸签 | 在可获取键盘焦点的编辑窗口中修改 |
| 拖右下角把手 | 调整常驻卡片尺寸，宽度至少 280 pt、高度至少 300 pt |
| 点“取消固定” | 加入恢复区，可立即撤销 |

移动、内容拖放、目录投放、编辑和菜单跟踪期间不因指针离开而自动收回。没有持续摇摆、回弹或背景动画，因此减少动态效果不依赖额外开关。进度指示仅出现在加载或复制期间。

左右停靠使用屏幕的 `visibleFrame` 并留出内边距，避开 Dock 和菜单栏。按屏幕高度限制可见数量，超出时显示“更多”；全部夹项始终可从管理窗口找到。

## 三条使用流程

**常用目录：** 添加目录 → 点击纸签填写用途 → 靠边收起 → 点击展开 → 浏览或打开 Finder → 重启后保留。

**边看边写：** 主动夹住剪贴板图片 → 抓金属夹拉出 → 在原应用继续输入 → 按需缩放 → 拖回边缘。参照面板不成为键盘主窗口。

**交接材料：** 夹入文件 → 拖内容把手到接收应用 → 保留夹项和原文件。投放到真实文件夹时使用专门复制区，显示目录路径与结果，重名保留两份。

## 焦点与可达性

卡片与停靠入口是非激活面板，管理、编辑、设置和快速预览是普通窗口。管理窗口提供搜索、多选、分组、编辑和恢复的键盘入口；系统字体、符号及语义颜色支持系统辅助功能。

Esc 仅在本应用获取输入时处理，不监听其他应用的普通键盘输入。全局显示/隐藏通过用户配置的 Carbon 快捷键注册实现。原生文字选取、VoiceOver 完整导航和外部应用输入链路仍需持续实机验收。
