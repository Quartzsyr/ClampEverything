# v1.7.5

文稿翻页改为左侧装订线：整条左边保持固定，下一页揭起当前页，上一页把前页沿同一装订线放回。纸页图像、边缘和卷角共同弯曲与透视变形，带有随翻页变化的光影和投影。

所有纸页类内容（文字、代码、PDF / Word 等文稿、网页及纸质附件）加入轻微磨损边缘、细纤维描边与小卷角。装订边和夹口接触处保持平直，正文中部不受磨损裁切。支持轻拉纸角、松手回弹；拖动时自由角轻微起伏，尊重系统减少动态效果及关闭动效设置。

保留原页码、鼠标翻页、网页等比缩放及滚动、点击复制和拖出复制。安装包保留拟物箭头背景。

验证：163 项测试通过，覆盖装订线全程固定、反向揭页顺序、纸面弯曲、磨损幅度、正文边界、翻页中间帧像素，以及文稿、网页、复制拖放和新手引导回归。
