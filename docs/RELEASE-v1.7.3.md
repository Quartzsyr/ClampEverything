# v1.7.3

PDF 预览支持滚轮、触控板与页角按钮翻页，保持原页码。Word（DOCX / DOC）、RTF / RTFD、ODT 按文稿内容分页，复杂版式可以打开系统预览；其他仅提供缩略图的格式保留系统预览入口。

翻页时旧页沿夹边弯曲翻起，带有光影与投影，金属夹保持悬挂。限制一次触控板手势只翻一页，过滤惯性连翻，并按需渲染、最多缓存三页。

网页支持滚轮浏览正文和内嵌滚动区域，纸页边缘随滚动轻弯回弹。保留单击复制与拖出复制，滚动后不触发误复制；文字和代码滚动转交原生阅读区域。本次应用运行内记住各夹项的文稿页码和网页正文阅读位置。

支持关闭动效及系统减少动态效果。安装包保留拟物箭头背景。

验证：154 项自动化测试通过，覆盖 PDF 原页与边界、文稿连续分页及首段坐标、滚轮防连翻、阅读与复制手势、网页正文/内嵌滚动及位置恢复。最终 DMG 的原生背景解析、镜像校验和应用签名通过验证。
