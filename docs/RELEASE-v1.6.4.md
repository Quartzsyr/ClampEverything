# 屏幕夹子 v1.6.4

- 修复卡片拖拽卡顿风险：窗口逐事件跟随，减少纹理重绘与文件内容重复计算，停手和松手后回落。
- 边缘放下沿夹点翻回，快速再次拿起会取消旧收回任务。
- 夹取读取成功后按材质厚度夹紧；慢读取期间恢复普通指针，新夹项直接落在最终位置。
- 按内容区分瞄准光效：文字、图片、链接、文件夹和文件各有不同颜色与轮廓。
- 文字瞄准改为明显的逐行金黄色半透明底纹，保留字形可读性与边线；移动时降亮。
- 增强图片、链接、文件夹和文件的边线与光晕。
- DMG 新增“拖入 Applications”箭头、固定图标位置和安装说明。
- 使用内置 imagegen 生成独立磁盘图标，同时用于磁盘卷与本地 DMG 文件。

109 项回归测试通过，应用签名、镜像校验与安装布局检查通过。适用于 Apple Silicon、macOS 14+。开发签名，尚未经过 Apple 公证。
