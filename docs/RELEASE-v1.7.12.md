# v1.7.12

夹取完成提示改成放置点旁的小号“✓ 已夹住”，移除整只夹子图标与大块提示框。短暂显示后柔和淡出，普通说明和错误分别使用信息与感叹符号，错误保留较长阅读时间。新提示替换旧提示，开始下一次夹取会立即收起反馈。

设置的“使用习惯”新增“显示黄铜接收夹”，默认关闭；已有配置缺少此设置时也关闭。开关立即更新所有屏幕并自动保存，关闭会移除接收区域，已有内容不受影响；菜单栏和鼠标夹取继续可用。恢复交互默认值会关闭黄铜接收夹，使用引导不会强制开启它。

187 项回归测试通过，包括开关的默认值、编码持久化、各屏幕显示切换、已有夹项与引导的共存，以及提示的边缘定位、连续替换和自动消失。
