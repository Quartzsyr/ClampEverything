## 自 v1.6.4 以来的主要更新

### 夹子与内容共同悬挂、翻转

- 沿用原银夹形状，将尾部线环在铰接处向上掰起，挂在固定钉子上。
- 夹体、前后夹片和内容围绕同一悬点翻转；钉子留在原位，拖起时再呈现物件离开悬挂位置的动作。
- 统一展开与侧边收起时的金属夹尺寸，调整夹口在文件夹、纸页等内容上的接触位置，减少悬空和错位。
- 扩大收起状态的图片、文件夹等缩略内容，便于辨认；沿屏幕边缘拖动时保持收起，放下并重新悬停或主动点击后再展开。

### 极简的实物呈现

- 移除通用卡片底板、标题栏和常驻的底部操作小字，让内容本身成为可操作的实物。
- 文字与代码使用独立纸页，PDF / Word 直接展示文稿，网页展示页面，照片保持自身比例；音频、视频和压缩包分别以卡带、胶片、牛皮纸收纳袋呈现。
- 文稿类内容加入稳定的轻磨损边缘、细纤维和小卷角，正文区域保持完整；自由边在交互时轻弯、松手后回落。
- 文件夹改为薄纸文件袋：窄哑光边框、顶部索引耳、暖白内页与浅底折边，目录图标、行距和浏览箭头更紧凑。

### PDF / Word 阅读与点击复制修复

- 在夹住的纸页中使用滚轮、触控板或页角按钮阅读 PDF；Word / DOCX 等可读文稿按正文排版分页。
- 翻页沿左侧装订线向观看者掀起，自由边自然靠近，夹子和纸叠保持悬挂；翻动时预留绘制空间，避免纸边被裁切。
- 本次应用运行期间保留文稿页码；一次触控板手势最多翻一页，并控制渲染页缓存。
- 修复窗口因翻页临时扩展、收回时，坐标变化导致单击被误判为拖动的问题。
- 修复触控板惯性、非惯性滚动尾事件和结束 / 取消事件吞掉新点击的问题。按下纸页后保持本次点击，松开时复制原文件并显示「已复制」；新发起的滚动仍可正常翻页，拖出不会额外触发点击复制。
- 复制反馈依据实际写入结果显示；原文件失效或剪贴板写入失败时显示失败提示。

### 网页、代码和文件夹的实际内容浏览

- 网页使用实时 WebKit 页面，保持桌面布局后整体等比适配；宽网页、动态内容和宽图片可重新适配，长页面及内嵌区域继续支持滚动。
- 网页预览使用临时会话，不自动播放媒体或打开弹窗；正文位置在本次运行期间保留。展开网页会访问原站点，需要登录的内容取决于该独立会话可访问的页面。
- 代码和文本支持行号、语法着色、Unicode 和缩进；按纸页宽度调整字号，过长行在可读字号下限处换行，减少右侧裁切。
- 文件夹使用可复用原生列表，完整浏览当前目录，支持子目录进入、返回、回到根目录、显示隐藏文件和外部变化自动刷新。
- 保留文件行单击复制、拖出原文件和拖入复制；刷新与行复用不会将一次点击复制成其他文件。已覆盖千余目录项的末项可达性。

### 更自然的鼠标夹取

- 按住夹取键，瞄准目标后按下：内容从原位置轻微受压、抬起，再收拢到夹口；夹口随内容到达闭合，携带物件轻轻回摆。
- 文字、照片、文件、文件夹及不同媒体使用各自的过渡形态；收拢终点实时跟随鼠标，减少悬空、突然出现和交接跳动。
- 快速松开鼠标会完成已开始的夹取后放置；Esc、右键或退出夹取会取消未完成的操作。
- 完成提示改为放置点附近的小号勾选文字，短暂停留后淡出；修复「已夹住」等中文短提示被挤成两行的问题。
- 过渡展示来源内容的可视副本，原文件与来源应用中的对象保持原位。

### 大图长停留主体夹取

- 打开的大图或网页中的大图可在长停留后分析独立主体；短暂停留仍按整图夹取。
- 普通瞄准出现后，在同一主体上继续停留约 1.2 秒，待薄荷色轮廓及轻填色亮起，再点击夹取主体。
- 使用本地反差、Sobel 边缘和系统前景实例蒙版分析，识别结果不上传；独立主体保存为透明 PNG，保留孔洞和柔化边缘。
- 排除文件图标、按钮、Dock 和明确的缩略图；图像变化、窗口移动或结果过期会重新核对，无法明确分离时回退整图。
- 复杂背景、粘连、密集或遮挡主体不保证能逐一分离。可见图像分析需要屏幕录制权限，来源应用也须提供可读的图片区域。

### 设置、引导与安装体验

- 设置「内容大小」提供 12 类内容的独立调整（65%–180%），即时生效并本地保存，可恢复默认。
- 黄铜接收夹新增开关，**默认关闭**；关闭后仍可使用菜单栏添加、夹住剪贴板和鼠标夹取。
- 新手指引逐个展示 12 类真实示例与瞄准、夹紧、悬挂、展开、复制和拖出的动作，支持暂停、切换和重播，示例不写入用户资料库或剪贴板。
- 系统「减少动态效果」或关闭动效时保留功能、阅读和静态材质，减少几何运动。
- DMG 使用纸质箭头与银夹背景，固定应用与 Applications 的位置，带独立卷图标。已重新挂载最终压缩包到不同路径，核验背景可被 macOS 正确解析。

## 安装与升级

1. 从菜单栏退出正在运行的旧版屏幕夹子。
2. 打开 DMG，将 `ClampEverything.app` 拖入右侧 `Applications`；已有旧版时替换应用。
3. 从「应用程序」启动。应用常驻菜单栏，通过菜单打开设置。
4. 首次运行若被 macOS 拦截，确认下载来源后，在「系统设置 → 隐私与安全性」中处理打开提示。此版本为开发签名，未公证。
5. 鼠标夹取需开启「辅助功能」权限；图片区域或主体分析还需「屏幕录制」权限。授权后返回设置检查监听状态；签名身份变化时可能需要重新授权。

默认夹取键为 **Option**，也可在设置中更换：按住键、按下目标、保持按下拖动，松开鼠标放置；松开按键后可开始下一次夹取。左右边缘附近会自动吸附，屏幕中间可悬浮参照。

升级会继续使用原资料库 `~/Library/Application Support/ClampEverything/`，替换应用不会主动清空夹项。重要资料可在升级前备份整个资料库；原文件仍在原位置。

## 兼容范围与已知边界

- 最低系统要求 macOS 14，安装包仅包含 Apple Silicon 架构；未提供 Intel / Universal 构建。
- 跨应用识别取决于来源应用公开的辅助功能信息；密码框和未暴露的自绘内容无法保证夹取。
- DOCX 等格式的纸页预览使用正文排版；复杂表格、浮动图形、特殊字体的精确版式请使用系统预览或原应用。
- 网站可访问性、登录状态、云文件下载和第三方应用拖放能力仍受相应应用及系统限制；尚未完成完整第三方应用与多屏热插拔兼容矩阵。
- 宣传网页是独立浏览器演示，不直接操作用户的 Mac 文件系统或真实聊天账户；网页修改不等于 DMG 内增加了网页场景功能。
