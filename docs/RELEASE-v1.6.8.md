# 屏幕夹子 v1.6.8

- 放大收起状态的缩略图、文件夹与材料组，增加入口高度和侧边间距，夹子保持小尺寸。
- 拖动经过边缘夹项时不触发悬停展开；收起夹项沿边拖动保持缩略，放到屏幕中间后才展开。
- PDF 支持页码与翻页，DOCX 等办公文档支持系统内嵌预览和独立快速预览。
- 代码与文本增加行号、语法着色、滚动和复制，限制大文件读取量。
- 网页预览展示标题、地址、可用封面，带超时、缓存和失败退路。
- 修正原生文档预览的关闭策略，防止窗口与卡片重复释放；缩略回调隔离已删除或更换的来源。

127 项自动化测试通过。网页封面取决于网站提供的元数据；办公文档显示取决于系统 Quick Look 支持。适用于 Apple Silicon、macOS 14+。本地构建，尚未发布 GitHub。
