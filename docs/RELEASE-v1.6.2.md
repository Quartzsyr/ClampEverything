# 屏幕夹子 v1.6.2

- 修复拖拽时材质动画不断重启、照片纹理网格重绘与文件内容重复计算导致的卡顿风险。
- 窗口按每个鼠标事件直接跟随；材质反馈按真实速度计算并限制为 60 Hz，停手和松手后回落。
- 边缘放下改为沿夹点翻回，快速再次拿起会取消旧收回任务。
- 鼠标夹取读取成功后按材质厚度夹紧，携带材料随移动轻摆；文件类型在后台识别。
- 慢读取期间恢复普通指针，保留可取消的进度提示；新夹项直接显示在最终落点。
- 夹取前停留显示细亮边与蓝紫柔光，移动、滚动、夹取或取消时清除。

105 项自动化测试通过。支持 Apple Silicon、macOS 14 及以上；开发签名，尚未经过 Apple 公证。该轮未做界面手动性能测量。
