# 边缘拟物改版 · 2026-10-12

目标：无主界面，透明浮层只承载夹子和内容。

- 启动与重新打开应用不弹主窗口。夹项和恢复内容通过菜单栏按需列出。
- 边缘夹子宽 64 pt；空夹子接收拖入，不再显示按钮栏。
- 独立绘制钢丝柄、折叠钢板、夹口、高光及接触阴影，无新增位图依赖。
- 面板横向对齐物理屏幕边界；拖动距离边界 42 pt 内张口，释放吸附，左右镜像。
- 抓夹子移动，单击收放；抓内容拖出。展开为暖白纸面，移除标题栏、外描边与常驻工具栏。
- 编辑、打开、复制、预览、重新关联及取消固定保留于右键菜单。
- 已有项目组保留；这版没有新增项目组的可见入口。
- 复制反馈出现在展开纸面与菜单栏提示；原有恢复数据继续保留。

验证：release 编译、应用签名校验、28 项测试通过。导出并检查原生界面图（12-edge-material.png、02-folder.png）。实机跨屏拖动及第三方拖放尚未在本轮手工验证。

参考：https://github.com/alejandrobujan/tendedero ，参考透明窗口和物件交互思想，夹子形状与代码独立绘制。

## 2026-10-13 更新

- 菜单栏改为独立绘制的夹子轮廓，左、右键均打开操作菜单。
- 按需设置窗口采用系统 Liquid Glass（macOS 26+，较早版本降级材质），保留快捷键、显示行为、材质说明及恢复入口；实际窗口截图为 07-settings.png。
- 固定接收夹使用黄铜色与加号刻印；内容夹为银色。
- 纸张按 UUID 稳定生成不规则边缘、纤维、浅折痕和卷角。照片绕过纸面，按比例展示，增加薄厚度与边缘反光。
- 修复取消固定后旧视图保留模型、延迟回调复活旧窗口的问题：注销模型、取消悬停、断开内容视图引用，并检查布局对象身份和删除状态。
- 修复手动收回后立即被悬停展开；取消固定立即保存，恢复后生成全新窗口。
- 31 项测试通过，含重复取消—恢复—再取消、旧回调不得复活窗口、关闭后不得自动弹回、纸纹跨恢复稳定性。

## 按住鼠标夹取

增加“设置 → 鼠标夹取”：默认 Option，支持自定义单键、修饰键、组合键和冲突检查。系统事件监听只在启用且辅助功能已授权后注册；屏幕覆盖层仅在按住期间创建，显示张口金属夹光标，退出即移除。输入捕获不保存键盘内容。

点击按下及抬起成对拦截；Esc、右键、松开、屏幕变化、睡眠与监听超时会退出。辅助功能识别在后台读取点击目标的有限父节点，优先保存原文件与语义内容；图片可见区域截图通过 ScreenCaptureKit，需独立屏幕录制权限。图片保存不改剪贴板。

已验证按键状态、配置迁移、原有功能及设置布局；第三方应用命中识别与系统全局光标需要用户授予辅助功能后实机验收，不宣称支持所有自绘界面。
