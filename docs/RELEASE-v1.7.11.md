# v1.7.11

鼠标夹取加入约半秒的连续拟物过渡：对象局部轻压、抬起、收拢到夹口，夹子闭合后物件小幅回摆，接续拖动时的惯性。文字从可读行区域提起纸片，照片保持比例，文件和文件夹使用系统图标；各类型继续使用自身的纸张、文件袋、卡带、胶片或收纳袋材质，按柔软度和重量调整形变与速度。

动画终点随鼠标移动，夹口接触点固定在物件上边缘。收拢与携带使用同一材质组件和接触坐标，透明窗口预留垂下与摆动空间，避免物件悬空、边缘被裁或交接跳动。

快速松手会等待同一次夹取过渡完成再放置，不重复启动动画或重新读取来源图片。Esc、右键、松开夹取按键退出及系统会话切换会清理未完成的动画。关闭动效或系统减少动态效果时直接交接。来源应用中的对象不移动，过渡展示可视副本。

验证：184 项测试通过，覆盖全部材质的接触与落点、文字行区域和大范围目标、跨屏坐标、快速松手等待、取消重入、减少动态效果，以及过渡末帧与携带状态的原生像素一致性。完整回归包含 PDF / DOCX 复制、文稿外翻、网页和代码缩放、完整文件夹目录及拖出复制。
