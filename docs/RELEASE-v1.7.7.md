# v1.7.7

PDF / Word 等文稿翻页改为朝观看者向外掀起，左侧装订线保持固定。自由边在透视中靠近并放大，不再朝纸叠内部缩进；上一页沿同一路径反向放回。

纸页图像、磨损轮廓、卷角和阴影共同使用外翻后的投影。翻页时临时扩展绘制区域与原生窗口的透明留白，避免外翻纸边被原来的矩形裁掉；夹子和纸叠保持原来的屏幕位置，翻页结束恢复窗口大小。

保留网页与代码适配、鼠标翻页、页码、复制拖出及减少动态效果设置。效果见 [向外翻页关键帧](design/33-outward-page-turn.png)。

验证：169 项测试通过，覆盖自由边向外放大、装订线固定、正反翻页、外翻区域实际像素、窗口扩展时夹点不移动及结束后恢复。
