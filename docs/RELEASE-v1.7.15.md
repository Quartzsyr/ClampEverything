# v1.7.15

修复 PDF / DOCX 触控板点击复制仍可能没有反应的问题。之前仅过滤惯性滚动；非惯性的手指滚动结束 / 取消事件依然会清空按下状态，导致松开时没有复制和反馈。文稿按下后由本次点击持有交互，滚动尾事件不再取消它，释放后复制原文件并显示“已复制”。点击后迟到的结束 / 取消事件也不会误触发翻页。

正常滚动翻页与拖出原文件保留；拖动结束不会额外复制。只对文稿的按下稳定交互启用这项处理，其余内容原有滚动行为保持。

回归覆盖 CGEvent 到 NSEvent 的各滚动阶段、按下与非惯性滚动交错、释放后的结束事件、惯性事件、正常滚动恢复及拖出不误复制。PDF / DOCX 使用完整预览与原生窗口分发点击，验证真实配置的复制回调、系统可读的原文件 URL、页内反馈、翻页窗口扩展 / 收回。201 项测试通过。

本地安装包：`ClampEverything-1.7.15-arm64.dmg`。Apple Silicon，macOS 14 及以上；Apple Development 签名，尚未公证。本版本未上传 GitHub。
