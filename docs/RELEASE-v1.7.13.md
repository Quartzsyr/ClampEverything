# v1.7.13

修复夹取提示中文换行错乱：改用原生文字视图测量和绘制，短提示固定单行，较长说明和错误正常换行。保持轻量提示、深浅色适配和淡出，避免“已夹住”的最后一个字掉到下一行。

修复 PDF / DOCX 点击复制被翻页后残留惯性事件取消的问题。按下纸页会停止旧惯性并稳定悬停形变，松手后复制原文件；新的主动滚动仍取消点击，继续正常阅读。文稿阅读和按压状态合并处理，避免异步加载结束时提前恢复悬停动作。测试直接调用完整预览配置的实际复制回调，验证系统可读取的原文件 URL、中文与带空格路径、复制反馈，以及翻页窗口扩展和收回。

文件夹外观调整为薄纸文件袋：更窄的哑光彩色边框、缩窄的索引耳、暖白内页和浅折边。列表图标更小、行距更紧凑、箭头更淡，保留完整目录、子目录进入、原文件复制、拖出及目录变化自动刷新。

189 项测试通过，包含惯性事件吞点击的复现回归、真实 PDF / DOCX 复制、原生中文单行排版和完整目录浏览。
