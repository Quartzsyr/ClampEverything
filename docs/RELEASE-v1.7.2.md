新手指引升级为可控制的动态演示，逐个展示 12 类具体内容：文字、照片、PDF、Word、网页首屏、代码、文件夹、收纳夹、音频、视频、压缩包和其他文件。

每例演示瞄准、夹紧、边缘悬挂、翻转展开、点击复制及拖出复制。金属夹与内容一起转动，侧边收起保留小缩略图，拖出副本后原夹项继续保留。

支持自动播放、暂停、上一类 / 下一类、类型跳转、重播本例、完成后重看；空格暂停 / 继续、Esc 结束。移除旧指引的 14 秒自动消失，关闭时清理示例及播放任务，重新打开从首例开始。尊重系统减少动态效果与关闭动效设置。

PDF / Word 为原生渲染的首页，网页为离线 HTML 首屏，代码带语法颜色；示例均隔离于用户资料库，不写剪贴板。安装包保留纸质拟物箭头背景。

验证：147 项测试通过，覆盖完整类型与步骤顺序、暂停取消、重播导航、离线网页渲染、示例文稿和关闭释放；最终 DMG 的背景别名、应用签名和镜像校验通过。
