# 安装背景：折纸箭头

使用内置 imagegen 生成（非 CLI）。素材：`installer/paper-arrow-v1.png`。`scripts/make-dmg-background.swift` 将素材排版至 640×480 并叠加清晰的中文安装指引；Finder 的真实应用与 Applications 图标覆盖两侧留白。

## 完整提示词

Use case: stylized-concept
Asset type: macOS disk image installer background artwork, landscape 4:3, 1280 by 960.
Primary request: elegant minimal skeuomorphic installation background for a silver bulldog clip and loose paper desktop app. Warm ivory tactile paper with very faint fibers. One unmistakable large arrow pointing horizontally RIGHT, sculpted from folded warm white heavy paper, subtle curled edges, soft realistic contact shadows and a thin muted sage-green top surface accent. Arrow spans x=510..770 y=420..510, centered at (640,465). Two empty icon landing areas centered at (320,430) and (960,430), with only nearly invisible paper pressed circular impressions; these areas must be clear for actual Finder icons to be placed later. A tiny silver paper clip decoratively holds a blank small paper corner at upper left, unobtrusive. Product photography, soft top-left daylight, beautiful macOS stationery material realism, flat frontal view, ample negative space.
Constraints: NO TEXT, no letters, no logos, no application icons, no folder icons, no UI mockup, no border, no busy ornaments. The arrow is the hero, visible and points from left empty area toward right empty area. Entire background opaque.
