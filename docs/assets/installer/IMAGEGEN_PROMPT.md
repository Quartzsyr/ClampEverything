# DMG volume icon

Generated with the built-in imagegen tool, with a transparent background.

## Exact prompt

Use case: icon. Asset type: standalone macOS DMG installer volume icon for ClampEverything, square composition, transparent background. Create one polished skeuomorphic 3D icon: a compact brushed silver external installation disk with rounded corners, a small warm ivory paper label tucked under a realistic silver bulldog paper clip attached at the upper edge. Subtle sea-green accent inset on the disk, tiny understated amber status lamp. Crisp recognizable silhouette at 64px, disk front at gentle three-quarter angle, soft studio highlights, high-end macOS utility aesthetic, restrained materials, broad simple forms, generous transparent margin. No letters, no text, no logos, no arrows, no extra objects, no scene background, no mockup frames. Real alpha transparency outside the icon. This is a disk-image volume icon, distinct from an application icon.

Project asset: `dmg-volume-icon.png`.

The installation arrow and Chinese instructions are drawn separately with AppKit in `scripts/make-dmg-background.swift`, keeping them sharp and editable.
