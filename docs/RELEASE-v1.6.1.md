# 屏幕夹子 v1.6.1

把文件、文件夹、图片、文字和网页链接夹在屏幕边缘，随手参照、移动或拖出使用。

## 本次发行

- 所有材料统一绕夹点翻出与收回，增加拟物启动纸签。
- 十种材质支持拖动惯性与松手回摆，文件夹和材料组增加袋口、内页晃动。
- 设置新增“能夹什么”，展示内容类型、拟物形态和可拖动样品。
- 完善鼠标夹取：目标名称、图片预览、读取状态、落点与边缘吸附提示。
- 图片在拾取阶段读取并保存，放置时不重新截图；选中文字优先于父级网页链接。
- 读取、放置期间支持 Esc / 右键取消，隔离旧任务收尾，避免干扰下一次夹取。

## 安装

适用于 **Apple Silicon（arm64）、macOS 14 及以上**。
下载 `ClampEverything-1.6.1-arm64.dmg`，打开后将应用拖入 Applications。更新前退出旧版本；已有资料库不会因更新删除。

鼠标夹取需要辅助功能权限，图片区域夹取还需要屏幕录制权限。跨应用识别取决于来源应用提供的辅助功能信息。

**当前为开发签名版本，尚未经过 Apple 公证。** 首次运行如被系统拦截，请确认下载来源后，在系统设置 → 隐私与安全性中处理打开提示。更新后可能需要重新关联辅助功能授权。

## 校验与验证

同目录下载 DMG 和 `.sha256` 文件后运行：

```bash
shasum -a 256 -c ClampEverything-1.6.1-arm64.dmg.sha256
```
