# v1.7.6

修复网页缩小后文字仍偏大、导航越界、正文挤成窄列的问题。网页保持桌面宽度和原生字号排版，再通过原生视图整体等比缩小；不再依赖会触发最小逻辑字号补偿的 WebKit 页面缩放。用真实 GitHub 仓库页面复现并验证，首屏左右完整，长页面继续上下滚动。动态宽内容、尺寸调整、内嵌滚动与阅读位置继续生效。

代码与纯文本文件根据纸页宽度自动调整字号，长行在保持可读字号的前提下换行；不再依赖横向滚动阅读被截断的右半行。行号只标记原始行，与换行后的正文共同使用同一 TextKit 布局；保留缩进、Unicode、语法颜色、点击复制及拖出原文件。

设置中的网页、代码尺寸继续单独生效。保留左侧装订翻页、轻磨损纸张、自由角回弹与安装包的拟物箭头背景。

验证：166 项测试通过。原生 SwiftUI / WebKit 宿主测试覆盖实际坐标缩放、CSS 字号稳定、宽网页边缘、动态内容与滚动距离；TextKit 测试覆盖不同纸宽、长行换行、字号调整、原文与语法颜色保留。效果见 [网页](design/31-web-width-fit.png) 与 [代码纸页](design/32-code-width-fit.png)。
