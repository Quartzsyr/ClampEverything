# v1.7.9

文件夹简化为一张浅色内页和底部薄口袋边，移除重复的大文件夹图标、分隔线、多层纸叠与纹理线。顶部只保留目录名、项目数、必要的返回按钮和更多菜单；文件以单行图标与名称排列，长名称可悬停查看。

目录列表改用原生可复用行和固定滚动区域，完整读取当前目录；鼠标停在文件名、图标上也能滚动访问末项，支持触控板惯性。子文件夹用右侧箭头进入，返回使用浏览历史，避免路径别名影响根目录判断。支持在更多菜单切换隐藏文件。

当前目录的新增、删除与重命名会自动刷新，刷新时尽量保留正在阅读的位置。保留单击复制、拖出原文件、右键打开 / 快速预览 / Finder 显示、拖入复制及进度与失败重试；重用行时取消旧点击状态，避免复制成另一文件。

验证覆盖超过千项的目录读取、1,500 项列表末行访问和实际滚动、隐藏文件、子目录返回、外部文件变化、原文件拖出数据及复用行点击。效果见 [简化后的文件夹](design/34-minimal-folder-list.png)。

完整回归：176 项测试通过。
