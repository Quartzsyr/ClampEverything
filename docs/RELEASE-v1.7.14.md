# v1.7.14

新增大图主体夹取：短暂停留后点击仍夹整图；普通瞄准后继续在同一主体上停留约 1.2 秒，等待薄荷色轮廓亮起，再点击单独夹住。高亮贴合主体与孔洞，并随移动降低亮度，区别于整图的冷蓝边框。切换主体时重新等待；文件图标、缩略图及较小图片保留原有行为。

本机后台结合背景反差、Sobel 边缘和 Apple Vision 前景实例蒙版进行分析；不上传图片，识别不明确时仍夹整图。适用于来源应用能提供可读区域的大图，密集、粘连及遮挡的主体可能无法逐个分开。长停留分析使用现有屏幕录制权限，不自动请求或修改权限。

主体保存为透明 PNG，保留透明孔洞和柔化边缘；复制、拖出、重新加载及携带显示继续保持透明背景。沿用现有受压、抬起、收拢与放置动画。按下时重新确认图片未变化，并读取按下时的像素；目标变化则回退当前整图。移动离开、滚动、取消、退出夹取及会话切换清除旧识别和高亮，过时任务不能重新显示旧主体。

200 项测试通过。已实测系统前景分割接口；新增回归包括多主体分离、孔洞、透明边缘、主体轮廓、图标与缩略图排除、长停留与微移、过时任务隔离、按下校验、透明 PNG 保存、复制与重开。
