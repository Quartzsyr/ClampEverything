# v1.7.1

PDF / 文稿展开预览默认高度从 160 点提高至 256 点，网页首屏提高至 208 点，其他文件也适当放大，保持极简实物风格。

设置新增「内容大小」，PDF、Word / 其他文稿、网页、照片、文字、代码、其他文件、文件夹、收纳夹、音频、视频、压缩包可分别调整至 65%–180%，修改即时生效并本地保存，也可恢复默认值。图片与纸页保留比例，超出屏幕时自动缩小，金属夹和侧边缩略图不随展开尺寸变化。

安装包采用 imagegen 生成的纸张与折纸箭头，补齐 Finder 图标视图、背景和滚动位置元数据。构建校验最终压缩 DMG 在不同挂载路径下的背景别名解析、安装图标位置和应用签名。

验证：141 项测试通过，覆盖旧偏好迁移、不同类型的独立尺寸保存、尺寸范围、屏幕边界、即时更新及原有夹取拖放行为。Apple Silicon / macOS 14+。
